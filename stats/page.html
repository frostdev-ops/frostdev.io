How this is counted. The numbers are Cloudflare's request statistics for /kiln/downloads/, read once an hour. For a file of a megabyte or more, a download is the file's size in bytes sent: a download that was resumed or fetched in parts counts once, one that was given up counts as the part that arrived. For small files and text files it is a complete answer. “Requests” are complete answers.

Who. People: a current web browser. Launcher updates: the Kiln launcher fetching its own update. Tools: curl, PowerShell, NuGet, download managers. Automated: crawlers, link previews, scanners, and programs that claim to be a browser nobody runs any more. A program can claim anything, so these are estimates.

What is kept. Per day: file, country, kind of program, system, a count and the bytes. No IP address and no User-Agent text.
